# 成像模型、拟合方法与可靠性

## 1. 声明的成像模型

每个像素、每个颜色通道独立，假设场景静态、各帧已配准、曝光已统一解释。
检偏器透射轴方向为 θ 时，传感器线性强度建模为

```
I(θ) = A + B·cos(2θ) + C·sin(2θ)
     = A + R·cos(2(θ − φ))
```

参数：

| 符号 | 含义 | 量纲 |
|------|------|------|
| A | 角度恒定分量 | 强度 |
| B, C | 调变项的两个正交分量 | 强度 |
| R = √(B²+C²) | 线偏振调变幅度 | 强度 |
| φ = ½·atan2(C, B) | 偏振角 AoLP，范围 [−90°, 90°) | 角度 |
| DoLP = R/A | 线偏振度（要求 A>0） | 无量纲 |

模型的数学对称性：φ 与 φ+90° 在 `cos(2(θ−φ))` 下完全等价，偏振角只有
模 90° 的意义，不存在 0–180° 的方向辨识能力。

## 2. 能力边界（重要）

1. **A 不是“无反光真实颜色”**。未偏振镜面反射、圆偏振、探测器暗底等
   所有不随线偏振片旋转而变化的贡献都累加在 A 中。模型只看到一个总数，
   无法把未偏振镜面反射与漫反射拆开。
2. **不承诺去除不可区分的未偏振反射**。若需要把镜面/漫反射进一步分离，
   必须引入额外物理假设或额外观测（如多角度照明、偏振度先验），超出本
   模型声明的范围。
3. **弱响应区角度不可解释**。当 R 与拟合不确定度 σ_R 同量级时，φ 的
   不确定度发散，此时输出 `weak_response`，DoLP/φ 仅保留数值但界面不做
   可信解读。
4. **不是取最暗值**。`min_θ I(θ) = A−R` 只是模型在理想无噪声、角度覆盖
   充分且恰好采样到极小值时的一个特例；本工具对全部有效样本做加权最小
   二乘，并报告残差与不确定度。

## 3. 样本有效性规则（逐像素、逐角度）

出现以下任一情况的样本不进入方程，但**不影响同一像素其他角度**：

- 饱和：`I ≥ saturation`，传感器钳位使真实强度不可知；
- 运动：配准残差/外部标记表明该帧该位置错位，违反静态假设；
- 缺失：该角度无数据（NaN、遮挡、配准越界）；
- 非法：非有限值或负强度。

有效方程数少于 3 时三个参数不可辨识，输出 `insufficient_angles`；
全部样本无效输出 `no_valid_samples`。

## 4. 加权最小二乘与不确定度

设计矩阵 X 的三列为 `[1, cos2θ, sin2θ]`，权重 `w = 1/σ²`：

```
β̂ = (XᵀWX)⁻¹ XᵀWy,   Cov(β̂) = (XᵀWX)⁻¹
```

σ 由调用方给出（噪声标定值，或按曝光归一后的读数噪声）。R、φ、DoLP
的不确定度由协方差线性传播：

```
σ_R² = (B²σ_B² + C²σ_C² + 2BC·Cov(B,C)) / R²
σ_φ² = (C²σ_B² + B²σ_C² − 2BC·Cov(B,C)) / (4R⁴)
σ_DoLP² = (σ_R² + DoLP²·σ_A²) / A²
```

R→0 时 σ_φ 发散，这正是弱响应区必须标记而不是强行报角的原因。

## 5. 像素状态

| 状态 | 判定 | 解读 |
|------|------|------|
| `ok` | 物理约束满足且 R ≥ weak_snr·σ_R（默认 3σ） | 参数可解释 |
| `weak_response` | R < 3σ_R | 仅 A 可用，φ/DoLP 不可解释 |
| `insufficient_angles` | 有效角度 < 3 | 模型不可辨识 |
| `unphysical_fit` | A ≤ 0 或 R > A（预测出现负强度） | 数据违反模型前提 |
| `no_valid_samples` | 无有效样本 | 无数值输出 |

残差诊断另给出：残差 RMS、加权残差平方和、归一化卡方
（χ²/自由度）、最大绝对残差、超过 4σ 的残差异常计数。

## 6. 共同曝光解释

不同帧曝光时间 t 与增益 g 不同时，按线性传感器归一：

```
I_norm = I_raw / (t·g),   saturation_norm = saturation / (t·g),
σ_norm = σ_read / (t·g)
```

归一化是纯线性比例，A 与 R 同比例缩放，DoLP 不变。各帧饱和值不一致时
CLI 取最小饱和值以保守执行排除规则。

## 7. 配准

提供相位相关的整像素平移估计与平移校正，越界像素进入缺失遮罩。注意
相位相关假设帧间内容仅存在平移；偏振导致的强度调变本身会相关但不改变
纹理位置，强反光/大遮挡可能使估计偏差，建议优先使用机械固定拍摄或在
外部完成亚像素配准后直接传入数组。
