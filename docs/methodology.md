# 成像模型、拟合方法与可靠性

## 1. 声明的成像模型

每个像素、每个颜色通道独立，假设场景静态、各帧已配准、曝光已统一解释。
检偏器透射轴方向为 θ 时，传感器线性强度建模为

```
I(θ) = A + B·cos(2θ) + C·sin(2θ)
     = A + R·cos(2(θ − φ))
```

参数：

| 符号 | 含义 | 量纲 |
|------|------|------|
| A | 角度恒定分量 | 强度 |
| B, C | 调变项的两个正交分量 | 强度 |
| R = √(B²+C²) | 线偏振调变幅度 | 强度 |
| φ = ½·atan2(C, B) | 偏振角 AoLP，范围 [−90°, 90°) | 角度 |
| DoLP = R/A | 线偏振度（要求 A>0） | 无量纲 |

模型的数学对称性：φ 与 φ+90° 在 `cos(2(θ−φ))` 下完全等价，偏振角只有
模 90° 的意义，不存在 0–180° 的方向辨识能力。

## 2. 能力边界（重要）

1. **A 不是“无反光真实颜色”**。未偏振镜面反射、圆偏振、探测器暗底等
   所有不随线偏振片旋转而变化的贡献都累加在 A 中。模型只看到一个总数，
   无法把未偏振镜面反射与漫反射拆开。
2. **不承诺去除不可区分的未偏振反射**。若需要把镜面/漫反射进一步分离，
   必须引入额外物理假设或额外观测（如多角度照明、偏振度先验），超出本
   模型声明的范围。
3. **弱响应区角度不可解释**。当 R 与拟合不确定度 σ_R 同量级时，φ 的
   不确定度发散，此时输出 `weak_response`，DoLP/φ 仅保留数值但界面不做
   可信解读。
4. **不是取最暗值**。`min_θ I(θ) = A−R` 只是模型在理想无噪声、角度覆盖
   充分且恰好采样到极小值时的一个特例；本工具对全部有效样本做加权最小
   二乘，并报告残差与不确定度。

## 3. 样本有效性规则（逐像素、逐角度）

出现以下任一情况的样本不进入方程，但**不影响同一像素其他角度**：

- 饱和：`I ≥ saturation`，传感器钳位使真实强度不可知；
- 运动：配准残差/外部标记表明该帧该位置错位，违反静态假设；
- 缺失：该角度无数据（NaN、遮挡、配准越界）；
- 非法：非有限值或负强度。

有效方程数少于 3 时三个参数不可辨识，输出 `insufficient_angles`；
全部样本无效输出 `no_valid_samples`。

## 4. 加权最小二乘与不确定度

设计矩阵 X 的三列为 `[1, cos2θ, sin2θ]`，权重 `w = 1/σ²`：

```
β̂ = (XᵀWX)⁻¹ XᵀWy,   Cov(β̂) = (XᵀWX)⁻¹
```

σ 由调用方给出（噪声标定值，或按曝光归一后的读数噪声）。R、φ、DoLP
的不确定度由协方差线性传播：

```
σ_R² = (B²σ_B² + C²σ_C² + 2BC·Cov(B,C)) / R²
σ_φ² = (C²σ_B² + B²σ_C² − 2BC·Cov(B,C)) / (4R⁴)
σ_DoLP² = (σ_R² + DoLP²·σ_A²) / A²
```

R→0 时 σ_φ 发散，这正是弱响应区必须标记而不是强行报角的原因。

## 5. 像素状态

| 状态 | 判定 | 解读 |
|------|------|------|
| `ok` | 物理约束满足且 R ≥ weak_snr·σ_R（默认 3σ） | 参数可解释 |
| `weak_response` | R < 3σ_R | 仅 A 可用，φ/DoLP 不可解释 |
| `insufficient_angles` | 有效角度 < 3 | 模型不可辨识 |
| `unphysical_fit` | A ≤ 0 或 R > A（预测出现负强度） | 数据违反模型前提 |
| `no_valid_samples` | 无有效样本 | 无数值输出 |

残差诊断另给出：残差 RMS、加权残差平方和、归一化卡方
（χ²/自由度）、最大绝对残差、超过 4σ 的残差异常计数。

## 6. 共同曝光解释

不同帧曝光时间 t 与增益 g 不同时，按线性传感器归一：

```
I_norm = I_raw / (t·g),   saturation_norm = saturation / (t·g),
σ_norm = σ_read / (t·g)
```

归一化是纯线性比例，A 与 R 同比例缩放，DoLP 不变。各帧饱和值不一致时
CLI 取最小饱和值以保守执行排除规则。

## 7. 配准

提供相位相关的整像素平移估计与平移校正，越界像素进入缺失遮罩。注意
相位相关假设帧间内容仅存在平移；偏振导致的强度调变本身会相关但不改变
纹理位置，强反光/大遮挡可能使估计偏差，建议优先使用机械固定拍摄或在
外部完成亚像素配准后直接传入数组。

## 8. 可复跑的异常诊断

拟合给出的是"在当前角度声明与曝光假设下的最优解"，但残差大或出现负
分量本身不区分原因。诊断层在**观测副本与重拟合**上回答"残差从何而来"，
且与引擎共用同一个加权最小二乘求解器 `solve_wls`，保证诊断路径上的
正常像素得到与原引擎逐元素一致的分量（`max_abs_beta_diff = 0`）。

### 8.1 七类假设

| 假设常量 | 含义 |
|----------|------|
| `consistent_with_model` | 残差可由噪声解释，与模型一致 |
| `angle_order_mismatch` | 分析角顺序/声明错配 |
| `exposure_inconsistency` | 照片曝光不一致（逐帧乘性增益） |
| `angle_and_exposure` | 角度与曝光两类故障共同存在 |
| `local_motion` | 局部场景运动 |
| `ambiguous` | 证据不足，保留候选解释，不下单因结论 |
| `not_estimable` | 有效观测不足，无法诊断 |

### 8.2 三类反事实检验

每个采样点先做基线 WLS，再并行运行三类受控反事实（counterfactual），
比较残差平方和的相对下降，而不是看到大残差就归咎噪声：

1. **角度重配检验**：枚举角度索引的非恒等排列（K! 过大时按
   `max_permutations` 抽样），向量化批量计算每个排列下的加权 χ²。
   仅当基线 reduced χ² 已升高（≥ `angle_min_chi2`）且最佳排列相对收益
   ≥ `angle_rel_gain` 时，角度证据才算强，避免在纯噪声上被排列过拟合。
2. **逐帧增益检验**：对每一帧用 20–80% 截尾的 `I/predicted` 中位数估计
   稳健增益 g 及其 MAD。曝光故障是整帧常数倍增，因此显著帧必须同时
   满足 `|g−1| > exposure_gain_tol` 与 `|g−1|/MAD ≥ exposure_mad_z`
   （偏离大且空间散布小）；增益校正后 χ² 显著下降才采信。
3. **联合检验**：先做增益校正再重新枚举排列，检验两类修正是否都有
   不可替代的收益。只有当增益校正后 χ² 仍高于角度门限时，才允许角度
   与曝光并存为 `angle_and_exposure`，否则单因曝光即可解释。

### 8.3 全图普遍性门控与运动的局部性

角度错配与曝光不一致都是**帧级**故障，应在全图大范围像素上同时出现。
诊断要求对应候选在至少 `global_prevalence`（默认 20%）的可诊断像素上
成势，才提升为全局结论；仅在零星像素出现的重配/增益收益被降级为
`ambiguous`。局部运动则相反：热点必须在空间上聚成 4-邻域连通块、块内
异常占比 ≥ `motion_fraction` 且块大小 ≥ `motion_min_pixels`，孤立
热点不允许断言为运动，同样保留歧义。

### 8.4 逐采样点记录与体积控制

`PixelRecord` 对每个采样点保存：采用的角度序列、逐样本观测/预测/残差/
标准化残差、有效标记与排除原因、有效观测数、设计矩阵秩与条件数、
A/B/C、reduced χ²，以及三类检验的全部中间量（最佳排列、χ² 基线/最优/
相对收益、逐帧增益与 MAD、热点角度）、最终假设、候选解释、证据列表与
建议。记录为 JSON 可序列化类型。整幅诊断时正常像素只按 `record_fraction`
抽样留存，异常像素全保留；诊断包再对每类假设按 χ² 封顶（默认各 25 条），
完整的逐像素空间结论以 `sealed_hypothesis` 图保存在 `data.npz`，不丢失。

### 8.5 不自动改写数据的边界

诊断与建议只描述"可由用户执行的核查动作"，**不重排用户照片、不夹紧
负值、不删除可疑样本、不修改原拟合结果**。所有反事实都在副本上进行；
确实无法在候选解释间区分时输出 `ambiguous` 并保留候选，而不是强行归因。

### 8.6 诊断包与离线重建

诊断包是一个自包含目录：`manifest.json`（结论、证据、配置、封顶后的
逐点记录、区域包围盒）、`data.npz`（区域内原始观测、角度、遮罩、封存
假设图与基线 A/B/C）、`rebuild.py`（独立复算脚本）。`rebuild.py` 不读取
任何界面状态，从 `data.npz` 重新跑 `fit_pixels` + `diagnose_stack`，
逐像素比对封存假设并核查基线分量（容差 1e-6），可在复制到其他机器、
脱离原界面后重建同一结论。
